## 📌 Sobre o repositório

Este repositório reúne atividades e exercícios desenvolvidos durante meus estudos de programação utilizando a linguagem **C#** e o ambiente de desenvolvimento **Visual Studio**.

O objetivo é registrar minha evolução na lógica de programação, praticar conceitos fundamentais da linguagem e desenvolver habilidades na construção de algoritmos e resolução de problemas.

As atividades são organizadas de acordo com os conteúdos estudados, permitindo acompanhar minha trajetória de aprendizado e consultar os códigos desenvolvidos ao longo das práticas.

## 🎯 Objetivos

- Praticar lógica de programação utilizando C#.
- Desenvolver o raciocínio lógico e computacional.
- Compreender a estrutura e a sintaxe da linguagem.
- Resolver problemas utilizando algoritmos.
- Aplicar conceitos fundamentais de programação.
- Desenvolver autonomia na escrita e organização de códigos.
- Registrar a evolução dos conhecimentos adquiridos.

## 💻 Ambiente de desenvolvimento

As atividades foram desenvolvidas utilizando o **Visual Studio**, ambiente que permite criar, executar, testar e depurar aplicações em C#.

Para executar os exercícios, é necessário ter:

- [Visual Studio](https://visualstudio.microsoft.com/pt-br/)
- SDK do [.NET](https://dotnet.microsoft.com/pt-br/download)

## ▶️ Como executar os exercícios

1. Clone o repositório:

```bash
git clone https://github.com/yasminalba/exercicioc-.git
```

2. Abra o Visual Studio.

3. Abra a solução ou projeto desejado.

4. Localize o arquivo `Program.cs` correspondente à atividade.

5. Execute o programa utilizando o Visual Studio.

**Observação:** cada atividade pode possuir sua própria estrutura de projeto e solução.
